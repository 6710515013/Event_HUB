# EventHub

ระบบจัดการและค้นหากิจกรรมสำหรับนักศึกษา

## Features
- สมัครสมาชิกและเข้าสู่ระบบ
- แยกสิทธิ์ Student และ Organizer
- Organizer สร้างและจัดการกิจกรรม
- Student ค้นหาและลงทะเบียนกิจกรรม
- Dashboard สำหรับผู้ใช้งาน

## Technologies
- Python
- Django
- SQLite
- HTML / CSS / JavaScript

## Installation

### 1. Clone repository
git clone <repository-url>
cd EventHub

### 2. Create virtual environment
python -m venv venv

### 3. Activate virtual environment
.\venv\Scripts\Activate.ps1

### 4. Install dependencies
pip install -r requirements.txt

### 5. Run migrations
python manage.py migrate

### 6. Run server
python manage.py runserver

## Usage
อธิบายวิธีใช้งานสำหรับ Student และ Organizer
